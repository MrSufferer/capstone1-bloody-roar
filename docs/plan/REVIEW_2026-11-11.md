## Must fix

1. **Indexer dừng khi gặp reorg thường** (`apps/worker/src/indexer/reorg.ts:64-73`)
   - **What this is:** Reorg là khi chain đổi nhánh, vài block cuối bị bỏ. Indexer phải lùi lại và quét lại.
   - **Problem:** Giả sử deploy ở block 0, indexer đang ở block 300, `reorgWindow` là 64, và chain reorg 2 block. Hệ thống lùi về block 236. Code yêu cầu có một sự kiện escrow canonical đúng tại block 236. Hầu hết block không có sự kiện, nên `boundary` là `null`, và hàm ném `REORG_BEYOND_WINDOW`. Indexer dừng. Hàm này chạy lại ở mỗi tick (`apps/worker/src/jobs/indexer.ts:9`), nên alert webhook cũng gửi lặp lại mỗi tick.
   - **Fix:** Lưu hash của `reorgWindow` block canonical gần nhất (bảng mới hoặc cột JSON trên checkpoint, cần migration). Khi lùi, so hash tại `target` với hash đã lưu. Chỉ dừng khi thật sự lệch. Gửi alert một lần cho mỗi sự cố, không gửi lại mỗi tick. Viết test đỏ trước: reorg 2 block phải tự phục hồi; reorg sâu hơn cửa sổ phải dừng, không đổi cursor, và chỉ alert một lần.
   - **If we skip it:** Mỗi reorg nhỏ làm dừng indexer và cần người xử lý tay. Projection có thể chậm hoặc lệch.

2. **File zip bom làm đầy đĩa worker** (`apps/worker/src/runner/archive.py:29-47`)
   - **What this is:** Zip bom là file zip nhỏ nhưng giải nén ra rất lớn.
   - **Problem:** Hàm `target()` cộng dồn kích thước khai báo trong header zip (`file_size`) để giới hạn 200 MB. Nhưng `write()` copy byte cho đến hết stream, không giới hạn. Header có thể khai báo nhỏ trong khi dữ liệu thật rất lớn. File upload tối đa 50 MB có thể ra hàng GB trên đĩa worker.
   - **Fix:** Trong `write()`, đếm số byte thật đã ghi và dừng khi vượt giới hạn. Giữ kiểm tra khai báo như bước lọc nhanh. Test: zip chứa 300 MB số 0 (vài trăm KB khi nén) phải báo lỗi. Có thể truyền giới hạn qua tham số để test chạy nhanh.
   - **If we skip it:** Một người dùng có thể làm đầy đĩa worker và làm dừng toàn bộ hệ thống.

3. **Code của dev chạy khi cài đặt, có mạng** (`apps/worker/src/runner/sandbox.ts:79-80`)
   - **What this is:** Khi cài đặt, công cụ có thể chạy code trong project (ví dụ `setup.py`).
   - **Problem:** Với Python, lệnh `pip install . pytest` chạy `setup.py` của dev. Bước này chạy trong container với mạng `bridge` (dòng 80). Mạng này tới được máy chủ worker và các dịch vụ nội bộ. Dev có thể dùng để quét mạng nội bộ hoặc gọi các địa chỉ metadata của cloud.
   - **Fix:** Với PYTEST, không bao giờ build project. Chỉ cài dependency: đọc danh sách từ `requirements.txt` hoặc `project.dependencies` trong `pyproject.toml` (dùng `tomllib`), rồi cài với `--only-binary=:all:`. Test: project có `setup.py` độc hại không được chạy. Ghi trong runbook rằng khi deploy thật phải chặn egress tới dải IP nội bộ và metadata. Việc này nằm ngoài code.
   - **If we skip it:** Code của dev có thể gọi các dịch vụ nội bộ của worker.

4. **Secret của client bị đóng gói và gửi cho AI** (`apps/worker/src/jobs/source-snapshot.ts:46-76`, `apps/web/src/graphql/modules/ai/ai.module.ts:113-121`)
   - **What this is:** Snapshot là bản đóng gói toàn bộ source để dev tải về. Context là đoạn text của source gửi cho model AI.
   - **Problem:** `textFiles()` (dòng 26-37) đọc mọi file, kể cả `.env` và file khóa, rồi đóng gói vào tarball. Route tải snapshot cho dev tải về. `sourceContext()` gửi nội dung file (tối đa 80 KB) cho nhà cung cấp AI bên thứ ba. `scanAndMask` chỉ che thông tin liên hệ, không che secret.
   - **Fix:** Loại khỏi tarball và khỏi context các file `.env*` (trừ `.env.example`), `*.pem`, `*.key`, `id_rsa*`. Loại thêm file có dòng trông như khóa (ví dụ `PRIVATE_KEY=`, `API_KEY=`, `SECRET=`). Test: snapshot và context không chứa các file này.
   - **If we skip it:** Khóa API hoặc khóa riêng của client lộ cho dev và nhà cung cấp AI.

5. **Test run kẹt ở RUNNING khi worker chết** (`apps/worker/src/jobs/test-runs.ts:16-19`)
   - **What this is:** Job đánh dấu một run là `RUNNING` rồi chạy.
   - **Problem:** Nếu worker chết giữa chừng, không có gì đổi dòng này về trạng thái khác. Các lệnh kiểm tra `TEST_RUN_ACTIVE` (`apps/web/src/graphql/modules/submission/test-runs.module.ts:42` và `apps/web/src/lib/test-runs.ts:9`) sẽ chặn mọi lần chạy test khác của issue đó. Dev và client bị kẹt vĩnh viễn.
   - **Fix:** Ở mỗi tick, đặt các run `RUNNING` có `startedAt` cũ hơn timeout sandbox cộng 5 phút thành `ERROR`, với log "worker lost". Test: một dòng kẹt sau khi chạy job phải thành `ERROR`, và `TEST_RUN_ACTIVE` không còn chặn.
   - **If we skip it:** Một lần worker crash làm khóa cả issue cho đến khi sửa tay trong DB.

## Should fix

6. **Transaction DB giữ trong lúc clone** (`apps/worker/src/jobs/source-snapshot.ts:42-79`)
   - **Problem:** Toàn bộ `git clone` và `git archive` (tối đa 120 giây) chạy trong một transaction DB. Transaction giữ row lock và một connection của pool.
   - **Fix:** Transaction ngắn để chuyển trạng thái sang `PROCESSING`. Làm I/O bên ngoài transaction. Transaction ngắn cuối để ghi `READY` hoặc `FAILED`.
   - **Tại sao:** Tải thấp nên chưa gây lỗi, nhưng ở tải cao sẽ cạn pool.

7. **Gate nộp bài chỉ có ở server** (`apps/web/src/graphql/modules/submission/draft.module.ts:127`, `apps/web/src/lib/test-runs.ts:22-28`)
   - **Problem:** `prepareSubmitWork` kiểm tra có run `PASSED`. Nhưng contract nhận mọi lệnh `submitWork`. `deliveryHash` không chứa kết quả test. Dev có thể gọi contract trực tiếp và bỏ qua gate.
   - **Fix:** Không sửa code trong đợt này. Đây là quyết định sản phẩm (xem plan tính năng). Hiện trong UI phải ghi rõ gate chỉ là gợi ý, và client phải xem kết quả test trước khi release.

8. **Query GraphQL có ghi DB** (`apps/web/src/graphql/modules/chat/conversation.module.ts:36-39`)
   - **Problem:** `workConversation` là một `queryField` nhưng tạo conversation khi chưa có. Client có thể cache hoặc gọi lại query này, nên việc ghi xảy ra ngoài ý muốn.
   - **Fix:** Chuyển thành `mutationField`, hoặc giữ là query và chỉ trả về room đã có.

9. **Dependency còn `"latest"`** (`apps/web/package.json:27`)
   - **Problem:** Batch P3 chưa pin `@pothos/plugin-with-input`.
   - **Fix:** Pin theo phiên bản trong `bun.lock`. Không nâng cấp.

10. **Logic trùng lặp giữa worker và web** (`apps/worker/src/jobs/test-runs.ts:24,31-35,44` và `apps/web/src/lib/test-runs.ts:5-21`)
